# DevNexus: Sistema de Automatización de Bots

## Descripción
DevNexus es una arquitectura modular diseñada para la automatización de flujos de trabajo mediante bots. Utiliza **Puppeteer** para la interacción en navegadores y un sistema de eventos centralizado para manejar lógica de negocio de manera desacoplada.

## Tecnologías Principales
- **Node.js**: Entorno de ejecución backend.
- **Puppeteer**: Automatización de navegadores.
- **TypeScript**: Estructura de código robusta y tipada.
- **Vite**: Entorno de desarrollo rápido.

## Estructura del Proyecto
- `/src`: Código fuente principal con la lógica de eventos.
- `/boilerplate-bot`: Plantillas reutilizables para despliegue rápido.
- `server.ts`: Orquestador principal del sistema.
